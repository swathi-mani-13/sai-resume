04 Direct Video Manager & File Pipeline

A standout engineering achievement of the shacreatz platform is the in-browser Direct Video Manager. It eliminates the need for manual code updates by empowering the portfolio owner to publish new videos directly from any desktop or mobile device.

Interactive Modal Architecture
The modal dialog is accessible via the prominent + ADD VIDEO header button. It provides a drag-and-drop file picker, real-time MIME-type validation, video duration detection via HTML5 Media APIs, and immediate gallery synchronization.

End-to-End Video Upload Flow

Step 1: Ingestion

User selects or drags an MP4/WebM/MOV file. The system validates MIME type and file integrity.

Step 2: Live Preview

A temporary Blob URL is created. The video renders in modal preview with dynamic duration badge.

Step 3: Cloud Storage

The file is dispatched to Supabase portfolio-videos bucket with sanitized timestamped filenames.

Step 4: Persistence

Metadata is written to PostgreSQL table and immediately appended to the live gallery DOM.

Client-Side Validation & Error Recovery

The form controller in js/app.js implements robust defensive programming:

  • MIME Verification: Accepts only video/mp4, video/webm, video/quicktime, and video/x-m4v. Unsupported formats display a clear warning.
  • Metadata Extraction: When the file loads into the preview player, the loadedmetadata event extracts video.duration, formatting it into MM:SS format for display.
  • Instant DOM Injection: The gallery updates immediately with smooth CSS transitions without requiring a page refresh.
  • Item Deletion: Each uploaded card includes an active delete trigger that removes the record from both the cloud database and the live DOM.

05 Supabase Database & Cloud Storage

Data persistence is powered by Supabase, an open-source Firebase alternative built on PostgreSQL. The database schema guarantees referential integrity, while Row Level Security (RLS) ensures secure, authenticated interactions.

Database Table Schema: public.portfolio_videos

Column Name Data Type Constraints Description
id UUID PRIMARY KEY Auto-generated via gen_random_uuid().
title TEXT NOT NULL User-entered caption or title (e.g., "Apex Velocity Drift").
category TEXT DEFAULT Project tag (e.g., "Automotive Edit", "Instagram Reel").
video_url TEXT NOT NULL Public CDN streaming link from storage bucket or external URL.
file_name TEXT NULLABLE Original client-side filename for reference.
mime_type TEXT DEFAULT 'video/mp4' Content type identifier for video player negotiation.
file_size BIGINT NULLABLE Raw file size in bytes for storage quota accounting.
storage_path TEXT NULLABLE Internal bucket path used for targeted deletion operations.
created_at TIMESTAMPTZ DEFAULT now() Timestamp used to order projects in chronological sequence.

Row Level Security (RLS) & Storage Policies

-- 1. Enable RLS on video metadata table ALTER TABLE public.portfolio_videos ENABLE ROW LEVEL SECURITY; -- 2. Allow public read access to portfolio visitors CREATE POLICY "Allow public read access to portfolio videos" ON public.portfolio_videos FOR SELECT USING (true); -- 3. Configure public video storage bucket INSERT INTO storage.buckets (id, name, public) VALUES ('portfolio-videos', 'portfolio-videos', true) ON CONFLICT (id) DO UPDATE SET public = true;
Resilient Offline Fallback Engine
In the event of network disruption or before cloud credentials are configured, js/supabase-client.js automatically detects the uninitialized state and gracefully falls back to local storage and the 6 static master projects in js/projects-data.js. The website remains 100% operational at all times.

07 Security, Performance & Optimization

The architecture emphasizes defense-in-depth security principles and aggressive asset delivery optimization, ensuring visitor data safety and lightning-fast loading speeds.

Security Architecture

Serverless Secret Isolation

Supabase API credentials are managed as encrypted environment variables in Vercel. The serverless function /api/config.js exposes only the public anonKey to the frontend, preventing exposure of sensitive service keys.

XSS & Input Sanitization

User-submitted video captions are strictly sanitized before DOM injection using native textContent nodes and encoded text attributes, neutralizing Cross-Site Scripting (XSS) vectors.

CORS Policy Enforcement

The API serverless handler sets explicit Access-Control-Allow-Origin: * and standard HTTP methods (GET, OPTIONS) with early preflight termination.

Safe Storage Deletion

Delete operations are bound to explicit file paths within the authorized portfolio-videos bucket, preventing unauthorized traversal or data tampering.

08 Deployment Guide, Roadmap & Sign-Off

Deployment & Hosting Architecture

The application is configured for one-click deployment on Vercel or any standard web host:

  • Repository Structure: Standard root directory with index.html, css/style.css, js/app.js, and api/config.js.
